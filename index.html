HTML: Linguagem de Marcação de Hipertexto

HTML (HyperText Markup Language) é a linguagem fundamental da web. Ele define a estrutura e o significado do conteúdo exibido em páginas da internet.

A web é formada por documentos interligados — é daí que vem o termo “hipertexto”: são os links que conectam páginas entre si. HTML não é uma linguagem de programação, mas sim de marcação.

Um documento HTML é composto por tags que organizam o conteúdo em títulos, parágrafos, listas, imagens e muito mais.

Exemplo: <section><h2>Sobre Nós</h2><p>Somos especialistas em web design.</p></section>

CSS: Folhas de Estilo em Cascata

CSS (Cascading Style Sheets) é usado para definir a aparência visual dos elementos HTML. Com ele, podemos aplicar cores, fontes, tamanhos e posicionamentos ao conteúdo.

Enquanto o HTML estrutura o conteúdo, o CSS define o estilo. Isso torna o código mais organizado e fácil de manter.

Exemplo: p { color: blue; font-size: 18px; }

O estilo pode ser aplicado diretamente no HTML (inline), dentro de uma tag <style>, ou em um arquivo separado com extensão .css.

JavaScript: Tornando a Web Interativa

JavaScript é uma linguagem de programação usada para adicionar interatividade a páginas web. Com ele, podemos responder a eventos, alterar elementos e criar páginas dinâmicas.

JS é executado no navegador do usuário e permite criar experiências muito mais ricas.

Exemplo: alert("Bem-vindo ao nosso site!");

Outra aplicação comum é alterar o conteúdo de um elemento HTML usando JS com base em ações do usuário.
